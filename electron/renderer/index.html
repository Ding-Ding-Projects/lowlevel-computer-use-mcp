Safe operating rules

Headless first

Use a named desktop for each project and agent, then launch GUI apps there. Use HWND-targeted clicks, text, and hotkeys. Unqualified mouse and keyboard tools are intentionally foreground controls and require explicit consent.

Automatic prerequisites

The client silently runs uv sync and repairs AutoHotkey on Windows startup. Every child process uses hidden Windows flags and never launches through a shell.

Trusted LAN

The API intentionally has no key because the user agreed to a trusted LAN. It grants the full toolset, commands, and file transfers to reachable clients; use a private bind address or firewall rule.

Documentation

The older GitHub Pages site remains the primary explanatory guide. This manual is the local control surface; the site contains the feature articles, configuration, failure modes, security notes, and verification evidence.
