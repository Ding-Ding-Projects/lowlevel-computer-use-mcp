Electron manual client

Tab groups and bulk close

Searchable, pinned, grouped tabs with an honest preview before any bulk close.

What it does

Settings keeps independent searches for the current strip, group tabs, group names, and every app-owned tab. Create, rename, collapse, expand, reorder, pin, and move tabs between groups. Right-click opens a bounded menu with its own search, group moves, pinning, and Edit tab appearance…; Shift+right-click remains the direct appearance shortcut.

Safe bulk close

Match visible tab labels with plain text by default or opt into the anchored JavaScript regex builder. Choose containing or inverse matching, scope the operation, preview the affected labels, and include pinned tabs only deliberately. Empty and invalid input stops at the preview; the two-key plus slider confirmation gates the actual close.

Verification boundary

The Electron contract check covers the controls and renderer wiring; the real Settings capture shows the shipped surface. Assistive-technology and live multi-window interaction evidence remains a host-specific follow-up.
